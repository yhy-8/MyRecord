# MyRecord 部署指南

本文是简明的**操作步骤**。代码结构见 [代码结构.md](./代码结构.md)。两端架构：服务端是数据中枢
+ 云端 AI；客户端是薄记录端。部署默认使用**自签证书 TLS 直连**（无需反向代理）。

---

## 1. 服务端部署（Linux + systemd，HTTPS 直连）

前置：Python ≥ 3.10。

```bash
cd <server工程根>                      # 含 server/ 子目录的独立工程根
pip install -r server/requirements.txt
python -m server.main cert --ip 服务端公网IP --ip 127.0.0.1   # 生成自签证书
python -m server.main run              # 前台启动验证（TLS 未配置会拒绝启动）
```

常驻（systemd）：

```bash
sudo cp server/deploy/myrecord-server.service /etc/systemd/system/
# 编辑该单元：ExecStart 的解释器路径与 WorkingDirectory 改成实际绝对路径
sudo systemctl daemon-reload
sudo systemctl enable --now myrecord-server
sudo journalctl -u myrecord-server -n 30   # 确认日志
```

服务端 `server/config.yaml` 里已含 TLS 配置段，`cert` 生成后填入证书路径即启用 HTTPS；
`server.main run` 会**强制 TLS**，未配置时直接拒绝启动（禁止明文传输）。

## 2. 签发链接凭证（单一共享 token）

凭证是**唯一共享 token**，不绑定设备：只要你持有它，任意客户端都能连上同步。签发会
**覆盖并删除旧 token**。

```bash
python -m server.main token create
# 输出：
#   device_id: sync
#   token: <一长串随机令牌>   ← 复制保存（服务端只存它的哈希）
```

把 token 写入客户端 `client/credentials.json`（格式见样板 `client/credentials.example.json`）：

```json
{
  "token": "<将说明文字替换成服务端签发的 token>"
}
```

凭证管理：

```bash
python -m server.main token list      # 查看当前凭证状态
python -m server.main token rotate    # 重新签发（覆盖旧 token）
python -m server.main token revoke    # 停用凭证
```

⚠️ `credentials.json` 是密钥，勿提交进仓库（已 gitignore）；`credentials.example.json` 是样板可提交。

---

## 3. 客户端部署

```bash
cd <client工程根>
pip install -r client/requirements.txt
python -m client
```

编辑 `client/config.yaml`：

```yaml
client:
  server_url: "https://服务端IP:8765"   # 启用 TLS 后必为 https
  verify: "./server.crt"                # 把服务端生成的 server.crt 拷到客户端并指向它
```

无 token 或离线时客户端也照常本地记录，上线后自动同步。

---

## 4. 数据备份与恢复

数据空间 `server/data/` 是唯一事实源，定期备份：

```bash
server/deploy/backup.sh [备份目录] [保留份数]   # 默认 backups/，保留最近 7 份
server/deploy/restore.sh <备份文件.tar.gz>       # 从备份恢复整个 data 空间
crontab -e                                        # 建议每日定时执行 backup.sh
```

---

## 5. 部署后自检清单

1. `systemctl status myrecord-server` 为 active；
2. `python -m server.main token create` 完成且 token 已写入各客户端 `credentials.json`；
3. 客户端 `python -m client` 能启动、完成首次同步、写入一条记录能即时到达服务端 `data/Records/`；
4. 服务端已填模型密钥，自动任务能调度；
5. 全程 HTTPS（自签证书直连）已生效。
